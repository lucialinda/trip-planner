TASKS.md 파일을 읽고 써서 작업을 관리한다. 파일이 없으면 새로 만든다.

## TASKS.md 형식

```
# Tasks

## 할 일
- [ ] 작업 내용

## 완료
- [x] 완료된 작업
```

## 동작

**`/todo`** (인자 없음)
1. TASKS.md 읽기
2. 할 일 목록을 번호와 함께 출력
3. 어떤 걸 할지 물어봄 (번호 또는 설명으로 지정 가능)

**`/todo add "내용"`**
1. `## 할 일` 섹션에 `- [ ] 내용` 추가
2. 추가 확인 메시지 출력

**`/todo [번호 또는 키워드]`**
1. 해당 작업 찾아서 시작
2. 작업 완료 후 `- [ ]` → `- [x]` 로 바꾸고 `## 완료` 섹션으로 이동

## 규칙
- 할 일이 없으면 "할 일이 없어요 🎉" 출력
- 번호는 현재 할 일 순서 기준 (완료 항목 제외)
- 작업 중 추가 태스크가 생기면 바로 TASKS.md에 추가
